# Team 34 - Diabetes Prediction Dashboard

This repo contains our Assignment 2 pipeline and Streamlit dashboard for diabetes prediction under temporal shift.

The raw CSV files are not tracked here because they are large. Put the dataset files inside `csv/` with their original names. The scripts will generate the rest inside `outputs/`.

## Quick start

We ran this project with `conda activate myenv`.

1. Make sure the required packages are installed in your environment.
2. Put the dataset CSVs in `csv/`.
3. Run the pipeline:

```bash
python src/04_aggregate.py
python src/05_split_and_label.py
python src/07_train.py
python src/08_continual.py
python src/09_explain_eda.py
python src/10_dump_joblib.py
```

4. Launch the dashboard:

```bash
streamlit run TeamXX_Assignment2_dashboard.py
```

## What is in the repo

- Feature aggregation from the raw EHR-style tables
- Temporal split into Dataset 1 and Dataset 2
- Stage 1 model training for Decision Tree, SVM, and MLP
- Continual learning and retraining on Dataset 2
- Metrics, plots, feature importance, and the final dashboard

## Notes

- Keep `csv/` local. It is ignored on purpose.
- `outputs/` is generated by the scripts and is also ignored.
- If the dashboard looks empty, rerun the pipeline so the artifacts are regenerated.
